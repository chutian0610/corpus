# 模板为编译期 Rust 常量，不做用户自定义模板

Wiki 模板（Generic / Research / Reading / …）在 Rust 中以常量定义、编译期确定，不提供用户自定义模板或外部 TOML 加载。理由：用类型系统对页面 schema（字段、类型、命名模式）做强约束，ingest 与 lint 的口径因此天然一致；模板由项目维护方策展，质量可控。

## Consequences

- 新增模板必须改代码发版，不能运行时注入。
- Vault 的模板迁移是显式独立操作（后续版本实现）；切换模板只影响新 ingest 的页面路由，不迁移旧页面。
- lint 分两层：核心规则基于核心不变量，模板特有规则基于模板层，两者都以编译期类型为口径。
